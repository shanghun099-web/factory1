말핀

말하면 지도에 핀이 찍히는 배송 도우미.
지도는 네이버, 주소 검색은 카카오 키를 써요.

🗺 네이버 지도 Client ID
1. ncloud.com(네이버 클라우드 플랫폼) 가입 → 콘솔
2. Services → Maps → Application 등록 (Web Dynamic Map 체크)
3. Web 서비스 URL에 이 앱 주소 등록 (예: https://아이디.github.io)
4. 발급된 Client ID 복사

🔍 카카오 키 (주소 검색)
1. developers.kakao.com → 내 애플리케이션 → 앱 추가
2. 앱 키 중 JavaScript 키 복사
3. 플랫폼 → Web → 이 앱을 올린 도메인 등록
   (예: https://아이디.github.io)
4. 제품 설정 → 카카오맵 사용 설정 ON
